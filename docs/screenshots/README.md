# README screenshots

Captured from Spark 0.3.0 on Windows using a separate application profile and WebView2 data directory.

- `spark-main.png`: the live, signed-out ChatGPT website at `https://chatgpt.com`.
- `sites.png`: the site list with the bundled services and their real domains.
- `window-size.png`: window sizing, pinning, and docking controls.
- `settings.png`: application preferences and global shortcut configuration.
- `add-site.png`: an unsaved DeepL entry using `https://www.deepl.com`.

The surrounding gradient is a separate backdrop window. The application and website content are screen captures; no local page fixtures or existing user sessions were used.
