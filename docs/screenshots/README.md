# README screenshots

Captured from Spark 0.3.3 on Windows by `.\gradlew.bat readmeCapture`, using a disposable application
profile and WebView2 user data folder. See [the media notes](../media/README.md) for how the capture works
and how to recreate it.

- `spark-main.png`: the live, signed-out ChatGPT website at `https://chatgpt.com`.
- `sites.png`: Your sites with the default services, Wikipedia, and their real domains.
- `window-size.png`: window sizing, pinning, and docking controls.
- `settings.png`: Settings with the global shortcut and General preferences.
- `add-site.png`: an unsaved DeepL entry using `https://www.deepl.com`, cancelled after the capture.
- `extensions.png`: the Extensions window with the four sample extensions over Wikipedia.
- `extension-popup.png`: Dark Reader's own popover identifying the open `en.wikipedia.org` page. This image
  is taller than the others because the popover extends beyond the Spark window.

The surrounding backdrop is a separate window. The application and website content are screen captures; no
local page fixtures, accounts, or existing user sessions were used.
